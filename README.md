# windows-folder-cover
A lightweight Windows utility for creating custom folder icons from images

V1 — Center-crop image mode

V2 — Full-image/Fit mode with improved folder handling and undo functionality

Usage
V1
1. Download `FolderCover-V1.bat`
2. Drag one or more folders onto the BAT file
3. Windows Explorer will refresh automatically

V2
1. Download FolderCover-V2.bat
2. Drag one or more folders onto the BAT file
3. Select numbers 1–3
4. Windows Explorer will refresh automatically

The original image files are not deleted, moved, renamed, or modified.
